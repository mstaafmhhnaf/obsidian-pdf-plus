## Overview

PDF++ extends Obsidian's built-in PDF viewer with text highlighting, annotation-to-note links, copy-as-markdown, and backlink tracking so PDF annotations integrate fully with the vault note graph.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Obsidian PDF++** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Text Highlighting** | Highlight PDF text in multiple colors with custom label tags |
| **Annotation Links** | Link vault notes to specific PDF annotations bidirectionally |
| **Backlink Panel** | See all vault notes that reference a specific PDF page or annotation |
| **Copy as Markdown** | Copy selected PDF text as formatted Markdown quotation |
